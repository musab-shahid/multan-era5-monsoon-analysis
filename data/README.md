# Data provenance

The `processed/daily_data.csv` and `processed/yearly_summary.csv` files are copies of the existing ERA5 analysis outputs in Google Drive; they were **not recomputed as part of GitHub publishing**.

Source: ERA5 hourly single-level reanalysis from the Copernicus Climate Data Store. Ten yearly NetCDF grids and the corresponding GRIB files are preserved in the [ERA5_Multan Drive folder](https://drive.google.com/drive/folders/1ED2SPbPAN9K2-oaKn_uFI0RqNxntEr04), not in this repository.

The daily CSV uses **Pakistan local-day** boundaries; the separate extremes figure uses UTC days. See [reconciliation](../docs/METHODOLOGY_AND_RESULT_RECONCILIATION.md).
