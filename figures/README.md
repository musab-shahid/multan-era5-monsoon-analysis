# Figure provenance

Eight graphics were extracted from saved outputs in the [analysis-only Colab notebook](../notebooks/Multan_ERA5_Analysis_ONLY_NO_DOWNLOAD.ipynb). The ninth, `full_year_2022_timeseries_ARCHIVED.png`, was recovered from the saved outputs in the earlier original notebook because the corresponding cell had not executed in the newer analysis-only run.

The archived plot uses the same underlying data and plotting logic, although its styling may differ. No plots were regenerated for GitHub publication.

**Daily-boundary caveat:** `extreme_rainfall_days_utc.png` uses UTC days, while annual wettest-day figures in the processed CSV use Pakistan local days. See [methodology note](../docs/METHODOLOGY_AND_RESULT_RECONCILIATION.md).
